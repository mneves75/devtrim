# 0.10.0 — uv fix, purge, usability (archived working notes)

Baseline: `05f7769` (main, clean). Owner: one Claude session (sole integrator).
Trigger: a real `devtrim scan` on the owner's Mac (830 findings, 97% full disk)
and the request to port Mole's purge and make devtrim easier to use.

## Defects found by using it (each test red before its fix)
- [x] uv cache never removable: uv writes an empty `.git` in `sdists-v<N>`
      (uv 0.9.24 `crates/uv-cache/src/lib.rs:439-449`); the sink refused it on
      every run. Narrow exception: empty regular `.git`, exact spelling, in
      `sdists-v<digits>` directly under a deletion root with a valid
      CACHEDIR.TAG (an unreadable tag only withholds it). Ten negative shapes,
      FIFO included.
- [x] uv lock: making uv removable exposed removal under a running uv. Apply
      takes uv's own `<cache>/.lock` exclusively without waiting (flock, as
      `uv cache clean`), after refusing a cache reached through a symlink.
- [x] trash-empty stopped at the first refused item. Continue + record.
- [x] Apply summaries called Trash moves "reclaimed" (observed: 25 GB
      "reclaimed", `df` unchanged). `bytes_trashed_estimate` + honest wording.
- [x] Git activity read in each entry's zone, cutoff in UTC: probe tests failed
      every evening in UTC-3. `TZ=UTC0` + `format-local`.

## Mole study (V1.56.0 `239c90d`, GPL-3.0 — reimplemented, never copied)
Ported the ergonomics, not the matching: `mo purge` matches ambiguous names
(build/dist/target/coverage) without manifest or Git and deletes permanently.
Issues #1427 #1459 #1551 #1290 record data loss.

## Features
- [x] `purge` = node-modules + artifacts, grouped by project, largest first;
      CLI + TUI (`p`); routed back to each category, which reasserts shape.
- [x] TUI: one line per finding + detail pane; Space / `A` narrow the plan;
      confirmation recomputed and states coverage; rows show effective danger.
- [x] `scan`: categories first with the command to act; `--all`; JSON complete.
- [x] Findings carry `project` (display only).

## Reviews

  one tag reading per permanent path, lock symlink guard, misroute test on a
