## Request and baseline

The owner's `/goal`: audit all source, fix every problem with failing-first
proof, review the TUI, redesign the site, verify, bump, release beta then
production. Branch `audit/0.12.1` from `9659f06` (main after the 0.12.0

## What changed

- Liveness: build-process probe limited to the current user (`pgrep -U`); a
  busy repository matched by identity as well as spelling; a superproject's
  build keeps only the submodules its index records as gitlinks. The first
  superproject rule over-protected (real purge preview fell from 259 to 89
  findings); the gitlink rule restored 259 with no errors.
- Protection: every folder at or above the home folder is protected; preview
  drops built-in protected targets; a root under a protected system folder
  warns. Consequence: a root spelled through `/System/Volumes/Data/…` offers
  nothing (the sink always refused it).
- Categories: unreadable folders named per category; npm/brew failures scoped
  to their own cache; npm asked without debug logs; Gradle's default home
  resolved through links; a linked Downloads/Desktop named, not scanned.
- Sink: a removal refused before anything was removed is restored, with the
  permissions RepairOwned added put back. Journal results keep an 8 KiB
  failure excerpt.
- Review fixes (f8a100d): autoreview (Astra) found builds in a superproject's
  sibling folders missed submodules (containment rule, 8cb1b97); the Fable
  reviewer found a superproject Git failure read as "busy" with exit 0
  (`repo_has_active_build` now returns `Result`, no process asks Git nothing)
  and the mode leak above.
- Signals: SIGHUP joins SIGINT/SIGTERM (exit 129). This replaces a SIGHUP
  ignored by `nohup`, so a nohup run stops when its terminal closes; there is
  no safe way to read the prior disposition and the crate forbids `unsafe`.
  `analyze` and `status --watch` restore the terminal on a signal.
- TUI: modified keys and bracketed paste never approve; the confirmation shows
  its own feedback (it covers the footer at 64×18) and caps the answer at 32
  characters; Esc no longer quits the too-small screen; `r` rescans from the
  outcome; row numbers widen past 999; terminal text keeps quotes literal.
- status: no health band over unread signals ("health unknown").
- Site: real `devtrim scan` frame added; taste inspect 0 FAIL.
- Video: npm overrides pin zod 4.6.7 and fast-uri 3.1.9 (Remotion 4.0.539 still
  pins zod 4.5.4).

## Lessons

- A later safety change can make an earlier eval vacuous: after the protect
  change, the firmlink-root liveness eval offered nothing for an unrelated
  reason and its mutant survived. The full planted run caught it only because
  rustfmt had also broken the anchor. Re-run the full planted list after any
  change to protection or root resolution.
- Never launch the planted runner under `nohup`: the SIGHUP mutant inherits the
  ignore and times out at an unnamed assertion.
- `cmd | tail` masks the exit code; read gate exits without a pipe.
