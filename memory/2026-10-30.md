# 2026-10-30 — 0.12.2 follow-ups, release, and 0.12.3

## Request and baseline

The owner pasted the 0.12.1 release report and said "do it all": every open
follow-up (gate plan P-01 to P-07, `roots = ["~"]`, the home-root warning,
`applied: false` on an unwritable journal, D9). Branch `release/0.12.2` from
`236f8b4` (the 0.12.1 closeout). The owner asked to skip staging and CI;
`scripts/release.sh` requires both, so neither was skipped.

## What shipped in 0.12.2

- A bare `~` root scans the home folder; an explicit root holding the home
  folder warns; an apply whose journal cannot be written reports
  `applied: false` before anything runs.
- `scripts/verify-live.sh` and its controls; release.sh requires the gate
  record and writes the verdict into the tag (P-01, P-02).
- `style-src` without `'unsafe-inline'`. `csp.py` went through eight Sol
  verification rounds: each found a spelling the standard-library parser and a
  browser read differently. The fix that held was a tokenizer of its own over a
  closed subset that refuses anything else (rejected alternative: refusing bad
  spellings one at a time, which never converged). It is documented as a lint,
  not a proof of browser equivalence.
- P-03 `security.txt` not applicable (RFC 9116 wants the host root); P-04
  hosted pins authoritative; P-05 `.scratch/` ignored. D9 measured 0.26 ms /
  1.87 ms, immaterial.

## Release

Gates, autoreview and Sol verify round 9 PASS at `2feb6df`; squash-merged as
`702d095`. Beta1 and stable share ZIP `06c03a06…`. The production publish hit a
GitHub HTTP 500; after confirming no release existed and main was unchanged, a
rerun of the failed job passed and the Homebrew closeout ran by hand
(`update-homebrew.sh 0.12.2`). `devtrim 0.12.2` is the sole install.

## Found during verification

- `optimize --task launch-services` exited 64 on macOS 27.2: `lsregister` no
  longer has `-kill` or `-domain`. The eval never saw it because the binary is
  an absolute path no stub replaces. Fixed in 0.12.3 with
  `-gc -r -f -apps local,user` (options from the installed tool's `-h`) and a
  contract test that reads that help. Not run for real here: it would change
  this Mac's Launch Services database.
- npm 12 refuses `config get cache` when the path contains a UUID (its redactor
  calls the value protected). Only test homes under a UUID scratch path hit it;
  devtrim fails closed for the npm cache alone. Left as a limitation.

## Lessons

- A fixed argv to an absolute-path system tool needs a contract test against
  the installed tool; stubs cannot cover it.
- A transient publish failure is safe to rerun only after proving no release
  exists and main has not moved.
