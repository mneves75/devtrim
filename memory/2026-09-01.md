# 2026-09-01

## 0.7.0: analyze, status, installers, semantic theme

Built from a competitive review of Scoppr and Mole. Reading Mole's source
changed the framing: its cleaning logic is 48,731 lines of shell deleting through
`rm -rf` in `lib/core/file_ops.sh`, while its Go is only the `analyze` and
`status` commands. The safety comparison therefore runs the other way from what
the feature lists suggest, and the useful thing to copy was coverage, not
posture.

One premise inverted under measurement. `CoreSimulator` is the largest directory
on this machine at 45.6 GB and looked like the obvious gap — but all 19
simulators report `isAvailable=true` with mtimes inside two weeks. They are in
active use, and `clean simulators` finding nothing there is correct. Mole and
Scoppr would offer to delete them; that is them being less safe, not devtrim
being deficient.

## What the reviews caught that no gate did

Four independent passes ran before release. Each found something real:

- `clean docker --apply` was broken end to end. The new report-only VM-image
  finding is pushed first by `scan`, and the apply loop refused any finding
  without a command authority, so it aborted before a single prune. The
  disclosure broke the feature it was added to. The skip is now on
  actionability, never on authority presence, so a forged actionable finding
  with no authority is still refused.
- `status` measured the sealed root volume. `df /` read 17% on a machine whose
  Data volume was at 94%. A disk-hygiene tool that reassures you when the disk
  is full is the worst possible failure mode. Health moved 100 → 75 after the
  fix.
- The monochrome danger ladder was defeated at the render site: `theme.bold()`
  adds BOLD to every level, collapsing moderate and high, while the theme's own
  test passed because it exercises `style()`. A gate measuring the wrong thing.
- `Target` had nine variants and the TUI menu referenced eight, so `installers`
  was reachable from the CLI and invisible in the interface.

Two of my own tests were passing vacuously. The help-overlay assertion searched
the whole frame for "quit", which the footer also contains, while the overlay's
real last line was clipped by a fixed 16-row popup. The colour positive control
read `Theme::from_env()` and would have failed in a shell exporting `NO_COLOR`.

## Instrument lessons

`script -q /dev/null` leaves the pty winsize at 0×0 on macOS, so ratatui draws
into a zero-area buffer and emits colour resets with no content — indistinguishable
from a broken interface. Setting `TIOCSWINSZ` from a Python `pty.fork` driver is
what made the TUI verifiable at all.

Locating text in a rendered buffer by `str::find` returns a BYTE offset while
cells are indexed by COLUMN; rows begin with a multi-byte border glyph, so the
two disagree. And `danger-1` is a prefix of `danger-10`, and the panel title
carries `danger-N` too — an unanchored needle matched the title, which renders
with no modifier.
