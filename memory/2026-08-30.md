# 2026-08-30

## Pre-production hardening

The review found one actionable data-loss path: case-variant Git metadata such
as `.GIT` could be traversed and previewed on case-insensitive macOS volumes.
The fix is layered across scanners, owner/category checks, central validation,
and fd-backed preflight, with positive controls proving an ordinary `git`
directory remains eligible. A separate `node_modules` authority review added
apply-time rejection for forged leaves, raw non-normal paths, symlinked
category ancestors, and dependency-nested owners.

Ordinary CI now runs checksum-verified ShellCheck, Gitleaks, and TruffleHog,
uses full Git history for secret scans, and has moved supported arm64 jobs to
`macos-15`. CI and release also prove Gitleaks detects a non-allowlisted
synthetic PAT before trusting a clean scan. Local release-surface verification covered Rust and MSRV suites,
structural gates, dependency and secret audits, all bounded fuzz targets, PTY
TUI cancellation, the arm64 release build, video gates, package contents, CSP
hashes, and desktop/mobile browser behavior.

## External boundary

No commit, push, publication, or deployment was performed. GitHub already has
an immutable v0.6.3 production release and the source landing page now points
to its verified asset, but the public GitHub Pages site remains on v0.6.2 until
an authorized deployment advances it.
