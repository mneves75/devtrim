# Plan 009 — 0.5.0 gap closure

Close the verified gaps from the 2026-08-26 devtrim-vs-Mole audit in one release,
without weakening any existing safety invariant. Every feature rides the existing
rails: preview-by-default, immutable plans, Trash-first, typed sink, fail-closed.

## Objective and success criteria

Audience: devtrim's users (terminal-fluent developers, safety-skeptical) and the
maintainer. Success: `devtrim clean artifacts` reclaims multi-ecosystem build
artifacts under the same guarantees as `node-modules`; every apply is journaled;
users can protect paths in config; build-in-flight targets are refused;
`brew install mneves75/devtrim/devtrim` works; fuzzing exercises the deletion
boundary; all release gates pass and 0.5.0 ships through the attested chain.

Merely acceptable: features land behind gates. Genuinely excellent: each feature
strengthens the safety story it touches (journal is write-ahead, whitelist is
enforced at the single sink so Mole issue #1427 stays unrepresentable here,
liveness fails closed).

## Tickets

### T1 — `artifacts` op (P0)
New `src/ops/artifacts.rs` implementing `Op`, registered in `ops::all()`,
`cli::Target::Artifacts`, and the TUI menu. Scans configured roots for build
artifact directories inside **conclusively stale Git repos** (same
`repo_last_commit` gate as `node-modules`; shared helpers extracted, not
duplicated). A directory is a candidate only when its name is on the closed list
**and** its ecosystem corroboration holds:

| Directory | Corroboration |
|---|---|
| `target` | sibling `Cargo.toml` |
| `.venv`, `venv` | `pyvenv.cfg` inside |
| `__pycache__`, `.pytest_cache`, `.mypy_cache`, `.ruff_cache` | name alone (tool-owned) |
| `.tox` | sibling `tox.ini`, `setup.cfg`, or `pyproject.toml` |
| `.nox` | sibling `noxfile.py` |
| `.next`, `.nuxt`, `.turbo`, `.parcel-cache`, `.svelte-kit`, `.astro`, `.expo`, `.angular` | sibling `package.json` |
| `Pods` | sibling `Podfile` |
| `.gradle` (project-local) | sibling `settings.gradle(.kts)` or `build.gradle(.kts)` |
| `.build` | sibling `Package.swift` |
| `.dart_tool` | sibling `pubspec.yaml` |
| `.zig-cache`, `zig-out` | sibling `build.zig` |
| any directory | valid `CACHEDIR.TAG` (regular file, exact spec signature) |

Deliberately excluded: `build`, `dist`, `out`, `vendor`, `bin`, `obj`,
`coverage` — ambiguous names whose deletion has bitten Mole (#1459 deleted
`dist` inside packages). `node_modules` and `DerivedData` stay owned by their
existing ops; the walker never descends into `.git`, `node_modules`, or a
matched artifact directory. Base danger 5, `Action::Trash`, size escalation.
Apply revalidates owner, staleness, and corroboration immediately before the
sink, exactly like `node-modules`.

### T2 — `protect` config (P2)
`protect = ["~/dev/keep", ...]` in `~/.config/devtrim.toml`. Entries expand `~`,
must be absolute after expansion, unknown fields still rejected. Enforced
deny-only at `validate_path_for_deletion` (the single sink): a target equal to
or under a protected entry (component-wise, ASCII-case-insensitive) is refused.
Scans additionally filter protected findings out of previews with an info
diagnostic. Config remains fail-closed: malformed protect entries are an error.

### T3 — Write-ahead apply journal + `devtrim history` (P1)
Append-only JSONL at `~/.local/state/devtrim/journal.jsonl`
(`$XDG_STATE_HOME/devtrim/journal.jsonl` when set). The filesystem sink writes an
`attempt` record before deletion and a `result` record after; command owners
(docker, simulators) journal their fixed argv the same way. A journal write
failure aborts the apply before deletion — a safety tool that cannot record must
not delete. `devtrim history [--limit N]` renders recent records;
`devtrim history --json` emits one `{"operation":"history","entries":[...],
"errors":[]}` document. TUI applies are journaled via the shared sink; a TUI
viewer is out of scope for 0.5.0.

### T4 — Liveness guards (P1)
Fail-closed, scoped where meaning is provable: for repo-scoped ops
(`artifacts`, `node-modules`), refuse targets whose owning repo is the cwd of a
running build/package process (`pgrep -x` over a fixed name list, then
`lsof -a -p <pids> -d cwd -F n`; fixed argv, no shell). For `xcode`, refuse
DerivedData children while `xcodebuild` runs. Probe errors fail closed (skip at
scan with a diagnostic, refuse at apply). Caches keep their existing
owner-command mitigation; broader guards are documented future work, not faked.

### T5 — Completions + man page (P2)
`devtrim completions <bash|zsh|fish>` via `clap_complete`; `devtrim manpage` via
`clap_mangen`, both to stdout. `--json` with either is a contract error. Formula
generates completions at install.

### T6 — Fuzzing (P1)
`cargo fuzz` targets: `validate_path_for_deletion` byte-path input (never
panics; `/System`-prefixed input always refused), the `clean()` normalizer, the
Docker size parser, and config parsing. Bounded runs (60 s per target) join the
documented local release gates; not CI (nightly toolchain).

### T7 — Distribution + docs + release (P0)
Homebrew tap `mneves75/homebrew-devtrim` with a binary formula pinned to the
attested 0.5.0 archive sha256, created after production promotion. README gains
an "Agents and automation" section (one-document JSON, typed actions,
nonzero-on-partial) — the agent-safe positioning. README/MANUAL/AGENTS/SECURITY
updated for artifacts, protect, history, guards, completions, brew. Signing and
notarization stay explicitly deferred (brew distribution moots the immediate
need); pathname TOCTOU stays documented, not overclaimed.

## Decisions and rejected alternatives

- **One release, seven tickets** rather than the 0.5.0/0.5.x/0.6.0 sequence:
  requested scope; risk is bounded because tickets are independent and the gate
  suite is strong. Rejected: feature-matching Mole's breadth (imports the blast
  radius that produced Mole's 2026 incidents).
- **Corroborated-name allowlist** for artifacts rather than Mole's broader name
  list: excludes exactly the ambiguous names with a public incident record.
- **CACHEDIR.TAG grants candidacy, inside stale repos, previewed, Trash-first**
  — the spec's meaning is "this directory is a cache"; corroboration comes from
  the exact signature. It never overrides `protect` or protected paths.
- **Journal at the sink**, not per-op logging: one choke point already exists;
  Mole's per-script wiring (whitelist skipped by `purge`) is the cautionary tale.
- **Write-ahead (attempt/result) records** over single-line logs: a crash
  mid-apply must be visible as an orphan attempt, or the journal lies.
- **Guard scope is narrow and honest** — a guard that pretends to cover
  everything (Mole's per-app guards grew incident-by-incident) is worse than a
  documented boundary. `rust-analyzer` is deliberately not in the process list:
  blocking every editor-open repo would make `artifacts` useless; active
  builders only.
- **`clean artifacts` naming** (noun category) over a `purge` verb subcommand:
  consistent grammar, honest label, no new top-level mutation entry point.

## Pre-mortem (top risks) and mitigations

1. Artifacts op deletes something a user wanted → corroboration + stale gate +
   Trash + preview + protect config + journal; generic names excluded.
2. Journal fail-closed bricks apply on odd setups → error message names the
   path and the `XDG_STATE_HOME` override; journal write is trivially small.
3. lsof/pgrep flakiness blocks applies → probe failure refuses only the affected
   repo/op with an explicit reason, never silently passes.
4. New deps raise MSRV or audit findings → clap_complete/clap_mangen pinned to
   MSRV-1.88-compatible versions; `cargo audit` gates.
5. TUI regression from new op → TestBackend coverage extends to the new entry;
   PTY manual pass required by release checklist.

## Gates (all mandatory before tagging)

fmt, clippy `-D warnings`, `ast-grep test` + `scan`, `cargo test` (stable +
MSRV 1.88.0), `cargo audit`, video npm gates, `bash -n`/shellcheck/actionlint,
Gitleaks, TruffleHog, bounded fuzz runs, autoreview P3, independent security
review, real PTY TUI pass. Staging `v0.5.0-beta<N>` → verified → production
`v0.5.0` promoting the exact beta artifact; landing page advances only after
promotion; tap formula pinned to the published sha256.
