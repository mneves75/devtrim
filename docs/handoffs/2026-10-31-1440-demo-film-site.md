## Dead ends

- **autoreview binaries:** autoreview refuses binary diffs (mp4, webp, png), and `--prompt-file` must be inside the repo.
  - Workaround: a throwaway worktree where the binaries are reverted in the index with `git update-index --cacheinfo`.
  - dcg blocks `git checkout <ref> -- <path>`.
- **dcg blocks:**
  - `rm -r` inside the repo, `find -delete`, and `mv … /tmp && rm` from the home folder: use `mv <path> ~/.Trash/<name>`;
  - heredoc redirects to variable paths: use the Write tool;
  - appends to `.git/info/exclude`, which is why the progress dashboard was skipped.
- **Headless screenshots:** Chrome headless `--window-size=390` renders wider and crops, which faked a "text cut off" finding. Use `agent-browser set viewport 390 844` instead.
- **Codex agent admission:** it can refuse with exit 75 when all 4 slots are busy. Retry in a loop.
- **Hold metric:** a 95% pixel-coverage measure of a phrase overstates its hold. The slow zoom grows the glyphs, and the easing tail needs a 99% opacity measure.
