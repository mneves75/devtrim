      About this snapshot

      This is a point-in-time inventory. Rerun devtrim dashboard with the same path to refresh it.

      Sizes are allocated blocks, with each hard-linked file counted once. APFS clones share blocks yet count in full each time, and snapshots keep blocks after removal, so available space, reported by the selected root’s filesystem, can move by less.
