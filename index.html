Clean your Mac like you deploy code.

devtrim is a local-first disk cleaner for macOS developer machines. It shows what every cache and build folder costs before anything moves, scores each action 1–10 for danger, and moves files to the Trash, recoverable until you empty it.

Free and open source · Apache-2.0 · macOS 13+ · latest release v0.12.3

Install v0.12.3 Read the manual

One careful pass replaces a risky ritual.

Developer Macs fill up silently.

DerivedData, model caches, simulators, Docker layers and six-month-old node_modules quietly eat hundreds of gigabytes.

Classify before you delete.

Every target gets a danger score from 1 to 10. Rebuildable caches are amber, unavailable simulators are caution, and a permanent Trash purge is red.

Some doors have no handle.

Docker volumes and Xcode Archives are never pruned. One typed deletion boundary and a protected-path denylist hold no matter which flags you pass.

Space you can trust back.

Files cleaned today stay recoverable from the Trash until you empty it. Permanent deletion needs a typed confirmation. Cleanup still carries data-loss risk: review the preview, keep backups, and grant macOS permissions yourself.

Preview first. Approve once.

Read the preview, leave one out, approve the exact plan. Download the demo

  1. The purge preview of two stale demo projects lists four build folders by size and name, each moving to the Trash: TRASH-FIRST, 4 of 4 selected, 7.8 GB, danger-5.
  2. The details pane shows the evidence for the first finding: the repository was last active on 2020-01-01, and a sibling Cargo.toml corroborates the Rust target.
  3. Each finding is danger-5. j moves down twice and Space leaves the third finding out: 3 of 4 selected, 7.2 GB.
  4. Pressing a raises the data-loss warning for that exact plan, 3 of 4 selected and 1 left out; y approves it.
  5. The approved findings move to the Trash, recoverable until you empty it; the one left out stays.
  6. Install with brew install mneves75/devtrim/devtrim.

One interactive TUI. Explicit commands for automation.

See before anything moves

devtrim / tui
Keyboard-first scan, preview, and confirmation with written risk labels. It reuses the same cleanup owners and rejects CLI bypass flags.
scan
Read-only report with estimated logical sizes, danger levels, and one-document JSON output for agents.
dashboard
A private, self-contained HTML snapshot of disk use: responsive treemap, folder navigation and search, volume free-space metrics and the existing category cleanup previews. --output saves it, --no-open skips the browser, and no inventory path ever becomes deletion authority.
history
Every apply is journaled write-ahead. Review what was attempted and what completed; an interrupted apply shows up as interrupted.
icloud
Large iCloud Drive files with logical and locally allocated sizes: a truthful storage inventory, not an upload-progress guess.

Move to the Trash first

caches
Hugging Face models, npm, Homebrew, uv, bun, cargo, Corepack, Gradle, Go modules, CocoaPods, the GitHub CLI and a closed list of editor and toolchain caches. All regenerate on demand; devtrim tells you the bandwidth cost instead of deciding for you.
node-modules
Applies exact previewed paths only when Git activity is conclusively older than 30 days. Unknown state is refused.
artifacts
Rust targets, virtualenvs, Pods, Gradle, Next.js, Turbo and Parcel caches, only with ecosystem corroboration, only in conclusively stale repos, never ambiguous names like build or dist.
xcode
iOS, watchOS, tvOS and visionOS DeviceSupport symbols and DerivedData. Archives are always listed but never touched.
toolchains + leftovers
Only provably unreferenced Swift toolchains are actionable, never one swiftly installed. Agent leftovers, ignored .scratch folders and devtrim worktrees are report-only.

Remove by typed command

docker
Unused images and build cache. Volumes are never pruned: a volume may hold your live database.
simulators
Deletes devices whose runtime is gone. Confirmation flags never add an unpreviewed erase-all.

Local scans. Guardrails by default.

  • No telemetry. The binary makes zero network calls of its own.
  • Nothing leaves your machine to be "analyzed".
  • Deletion means Trash first; --shred is opt-in per run.
  • Only exact validated targets reach the single filesystem deletion sink; incomplete measurements and display strings never become authority.
  • /System, /Applications, ~/.ssh and friends are refused unconditionally, and no flag overrides that.
  • Piped runs refuse to mutate unless consent is explicit.
  • macOS permission prompts require your manual decision; devtrim never bypasses Privacy & Security controls.

Install v0.12.3.

Homebrew

brew install mneves75/devtrim/devtrim

Installs the attested release binary plus shell completions and the man page.

Download for Apple silicon

SHA-256 sums are in the release assets. Verify before running:

shasum -a 256 -c SHA256SUMS.txt
gh attestation verify devtrim-*-macos-arm64.zip \
  --repo mneves75/devtrim \
  --signer-workflow mneves75/devtrim/.github/workflows/release.yml \
  --deny-self-hosted-runners

Build from source

git clone https://github.com/mneves75/devtrim
cd devtrim
cargo build --release --locked
cp target/release/devtrim /usr/local/bin/

Rust 1.88 or newer. No runtime dependencies beyond macOS 13+.

Run the scan you've been putting off.

It reads nothing it shouldn't, changes nothing without --apply, and keeps the safety net until you empty it. Provided AS IS; you accept the risk for applied targets.
