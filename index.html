Clean your Mac like you deploy code.

devtrim is a local-first disk cleaner for macOS developer machines. It shows what every cache and build folder costs before anything moves, scores each action 1–10 for danger, and moves files to the Trash, recoverable until you empty it.

brew install mneves75/devtrim/devtrim
Read the manual

Preview first. Approve once.

  1. The purge preview of two stale demo projects lists four build folders by size and name, each moving to the Trash: 4 of 4 selected, 7.8 GB, danger-5.
  2. The details pane shows the evidence for the first finding: the repository was last active on 2020-01-01, and a sibling Cargo.toml corroborates the Rust target.
  3. Each finding is danger-5. j moves down twice and Space leaves the third finding out: 3 of 4 selected, 7.2 GB.
  4. Pressing a raises the data-loss warning for that exact plan, 3 of 4 selected and 1 left out; y approves it.
  5. The approved findings move to the Trash, recoverable until you empty it; the one left out stays.
  6. Install with brew install mneves75/devtrim/devtrim.

Local scans. Guardrails by default.

Never touched

  • Docker volumes: a volume may hold your live database.
  • Xcode Archives: they are release artifacts.
  • /System, /Applications, ~/.ssh and friends are refused unconditionally, and no flag overrides that.
  • A repository with recent Git activity, and any folder holding a file its repository tracks.
  • Every path you list under protect in ~/.config/devtrim.toml.
  • No telemetry. The binary makes zero network calls of its own.
  • macOS permission prompts require your manual decision; devtrim never bypasses Privacy & Security controls.

Verify a release before you run it

SHA-256 sums are in the release assets, and every release carries signed build provenance.

shasum -a 256 -c SHA256SUMS.txt
gh attestation verify devtrim-*-macos-arm64.zip \
  --repo mneves75/devtrim \
  --signer-workflow mneves75/devtrim/.github/workflows/release.yml \
  --deny-self-hosted-runners

The threat model and how to report a vulnerability are in SECURITY.md.

Install v0.12.6.

Homebrew

brew install mneves75/devtrim/devtrim

Installs the attested release binary plus shell completions and the man page.

Download for Apple silicon

Build from source

git clone https://github.com/mneves75/devtrim
cd devtrim
cargo build --release --locked
cp target/release/devtrim /usr/local/bin/

Rust 1.88 or newer. No runtime dependencies beyond macOS 13+.

It changes nothing without --apply and keeps the safety net until you empty the Trash. Provided AS IS; you accept the risk for applied targets.
