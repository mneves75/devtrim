The problem

Developer Macs fill up silently.

DerivedData, model caches, simulators, Docker layers and six-month-old node_modules quietly eat hundreds of gigabytes.

The choice

Classify before you delete.

Every target gets a danger score from 1 to 10. Caches are green. Simulator contents are red. The score decides how much you must confirm.

The boundary

Some doors have no handle.

Docker volumes are never pruned. Xcode Archives are never pruned. A protected-path denylist no flag can override.

The result

Space you can trust back.

Everything cleaned today is restorable from Finder tomorrow. Permanent deletion needs a typed confirmation that matches the size.

Seven commands. Kept intentionally narrow.

scan

Full read-only report of every reclaimable category, with real sizes and danger levels. JSON output for agents.

caches

HuggingFace models, npm, Homebrew, uv. Re-downloads on demand — devtrim tells you the bandwidth cost instead of deciding.

node-modules

Sweeps only repos without commits in the last 30 days. Monorepo-aware, nested-store aware, lockfile-aware.

xcode

DeviceSupport symbols and DerivedData. Archives are always listed but never touched.

docker

Unused images and build cache. Volumes are sacred — a volume may hold your live database.

simulators

Deletes devices whose runtime is gone. Erasing contents of live simulators requires --yolo.

toolchains + leftovers

Duplicate Swift toolchains (Xcode's own unaffected) and AI-agent scratch directories.

icloud

Big files queued for iCloud upload, with local-materialization status — so eviction happens after upload, not before.

Local scans. Guardrails by default.

  • No telemetry. The binary makes zero network calls of its own.
  • Nothing leaves your machine to be "analyzed".
  • Deletion means Trash first; --shred is opt-in per run.
  • /System, /Applications, ~/.ssh and friends are refused unconditionally — no flag overrides.
  • Piped runs refuse to mutate unless consent is explicit.

Install v0.1.0.

Download for Apple silicon

SHA-256 in release assets. Verify before running:

shasum -a 256 -c SHA256SUMS.txt

Build from source

git clone https://github.com/mneves75/devtrim
cd devtrim
cargo build --release
cp target/release/devtrim /usr/local/bin/

Rust ≥ 1.85. No runtime dependencies beyond macOS 13+.

Run the scan you've been putting off.

It reads nothing it shouldn't, changes nothing without --apply, and keeps the safety net until you empty it.
